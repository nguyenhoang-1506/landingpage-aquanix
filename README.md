# Aquanix landing page (static)

Site tĩnh hoàn chỉnh: index.html ở gốc + assets/, tokens/, styles.css, _ds_bundle.js, 3 file .jsx.

Đưa lên GitHub Pages: copy TOÀN BỘ nội dung thư mục này vào GỐC repo (index.html phải ở gốc), push, rồi Settings → Pages → Deploy from branch → main / (root).
Giữ nguyên cấu trúc thư mục — ảnh tham chiếu tương đối ./assets/... File .nojekyll giữ cho Pages không bỏ file bắt đầu bằng "_".
Cần internet để tải React/Babel/QR từ CDN.
